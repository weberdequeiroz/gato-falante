Controle dos aparelhos, recados e registros. Os dados ficam no repositório do jogo no GitHub.

🔑 Entrar

Use um token do GitHub com permissão de escrita no repositório weberdequeiroz/gato-falante. Ele fica guardado só neste navegador.

Como criar o token (uma vez só)
  1. No GitHub, abra Settings › Developer settings › Personal access tokens › Fine-grained tokens e toque em Generate new token.
  2. Em Repository access, escolha Only select repositories e marque gato-falante.
  3. Em Permissions › Repository permissions › Contents, escolha Read and write.
  4. Gere o token, copie e cole aqui embaixo.

Conectado ✅

🔒 Bloquear aparelho

O código aparece no jogo em Ajustes › Este aparelho. O bloqueio vale na próxima vez que o aparelho abrir o jogo com internet.
